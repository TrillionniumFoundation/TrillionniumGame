# Trillionnium Nakama

Independent real-time multiplayer service for Trillionnium World.

This repository is intentionally a bootstrap skeleton. It will host Nakama
runtime modules for matchmaking, rooms, presence, authoritative match state,
and replay-event-root production. Product gameplay remains in World; research
evaluation remains in Hepta; finality and proofs remain in Chain.

## Start work

1. Work only from `/home/alex/projects/trillionnium-nakama`.
2. Run `bash scripts/project-preflight.sh`.
3. Create a focused `feature/nakama-*` branch.
4. Define or update a versioned contract before coupling another repository.

No existing World game-server code or legacy E2E code has been copied here;
ownership must be extracted deliberately behind contracts.
