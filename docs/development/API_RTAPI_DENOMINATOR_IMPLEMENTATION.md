# API / RTAPI machine denominator implementation

Status: **candidate implementation; SG1 remains open**  
Plan position: W0 `TG-W0-002`, supporting W2 and `DEN-API` / `DEN-RTAPI`.

## Delivered

The standard-library-only generator performs two deliberately separate operations:

1. `--fetch` downloads four files at reviewed immutable commits and rejects any Git blob mismatch.
2. offline generation parses only that source snapshot and emits deterministic canonical JSON.

Pinned inputs:

- Nakama `apigrpc/apigrpc.proto`;
- Nakama `apigrpc/apigrpc.swagger.json`;
- nakama-common `api/api.proto`;
- nakama-common `rtapi/realtime.proto`.

Generated API leaves cover gRPC services/methods, Proto HTTP bindings, Proto messages/fields/enums, and Swagger operations/schemas/properties. Realtime leaves cover messages, fields, enums and realtime envelope members. A separate candidate report reconciles Proto RPCs and HTTP annotations against Swagger operations and routes; every mismatch remains visible.

## Fail-closed state

Every generated leaf initially has:

```text
classification = unclassified
mandatory = null
status = planned
```

Every manifest has:

```text
status = candidate-unclassified
unclassified_count = leaf_count
sg1_eligible = false
compatibility_credit = false
```

`--require-sg1` therefore fails. Candidate generation cannot close SG1 or earn C1. Classification, owner/task/test review and independent evidence are separate follow-up work.

## Determinism and source integrity

The CI job:

- validates exact Git blob identities;
- runs parser/unit tests and malicious source-tamper rejection;
- generates twice in clean output directories;
- requires byte-identical output;
- checks minimum nonempty leaf counts;
- proves SG1 promotion fails;
- uploads exact-head candidate artifacts and SHA-256 manifests.

Absolute checkout paths, timestamps and runner identities are intentionally absent from generated bytes.
