# World command deployed runtime evidence policy v1

Evidence is creditable only when it is bound to the exact Git commit and tree, produced by the exact-head workflow, includes raw per-scenario artifacts plus SHA-256 manifest, and is independently reviewed.

Local source checks, synthetic unit tests, fixture-only execution and an empty GitHub check collection cannot be promoted to deployed or production evidence.

The five-scenario isolated report can close only the bounded single-host fault-lab rows. It cannot close multi-host fencing, 24-hour endurance, compatibility drain, rollback rehearsal, public online, player markets, CEX settlement or any Trillionnium Chain row.
