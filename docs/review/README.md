# Independent review

- `INDEPENDENT_REVIEW_MATRIX.json` records protected domains, required reviewer roles, assignments, conflicts and blocking gaps.
- `../governance/GITHUB_ADMIN_ACTIVATION_RUNBOOK.md` defines the independent review required after GitHub administrator mutations.
- `../evidence/INDEX_CONTRACT.md` defines review fields required before evidence can influence gaps or gates.

An empty assignment list is intentionally fail closed. This directory does not appoint reviewers or prove that a review occurred.
